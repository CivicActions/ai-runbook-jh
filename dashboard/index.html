ai-runbook-jh: Skills Explorer

Six phases. A skill for each move. Voice and security run through all of them.

How you use the skills

  • Autonomous chain. An agent runs the phases end-to-end, invoking skills as their triggers fire. Minimal hand-driving.
    You(paste the ticket body) Triage this and bring it to ready-for-estimation.
    AgentRuns triage → ticket-refinement → definition-of-done, hands back a refined ticket to paste back into the tracker.
  • One-off. Pull a single skill when you want it. No chain, no agent in charge.
    You@check-tone on this commit message.
    AgentRuns only check-tone. Nothing before or after.
  • Mix. Agent drives some phases; you take the wheel for others. Most common in practice; freedom is the point.
    You(write the plan by hand) Implement step 2 of plans/NSF-13412-plan.md.
    AgentRuns Build skills against the plan.
    YouTake back over for commits and the handoff.
Card accents: Foundation Voice cross-cutting Security cross-cutting Foundation: called by other skills more than invoked directly. Cross-cutting: not tied to a phase. check-tone fires on anything written for an audience; security-check fires on anything touching secrets or sensitive data.
